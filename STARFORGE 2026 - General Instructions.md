# **STARFORGE HACKATHON 2026**

# Official Submission Guidelines

# General Guidelines

* **Team Size:** Each team must consist of 2–4 members.  
* **Problem Selection:** Teams must select one of the officially released problem statements and build their solution around it.  
* **Documentation:** Clearly explain your solution, technical approach, tech stack, architecture/workflow, and prototype.  
* **Integrity:** Plagiarism or copied solutions will lead to immediate disqualification.  
* **Decision Authority:** The decisions of the judges and the organizing committee are final.

# PPT Submission Rules

* **Template:** Use the official STARFORGE PPT template exclusively.  
* **Accessibility:** The PPT must be publicly accessible.  
* **Final Submission:** Submit only the final version of the PPT via the official submission link before the deadline.

# Video Submission Rules

* **Duration:** Videos must not exceed 4 minutes.  
* **Access:** The video link (Google Drive) must be set to "Anyone with the link can view."  
* **Content:** The video must clearly explain your understanding of the problem, your technical approach, and include a demo if available.

# GitHub Repository Rules

* **Visibility:** The repository link must be public.  
* **Documentation:** The repository must contain a comprehensive README and all required project documentation.

# Hugging Face Rules

* Create your hugging accounts, will be required in further rounds and research publishings.

# WhatsApp Community Rules

**Communication:** Participants must regularly monitor the official STARFORGE WhatsApp Community for critical announcements and updates.
