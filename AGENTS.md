# STARFORGE 2026 Hackathon — AGENTS.md

## Project Context
This is a hackathon submission for STARFORGE 2026 (JSS University, Noida). No code exists yet — this repo will contain the team's solution.

## Tracks (choose one)
- **VoxForge**: Build a voice agent using **Rime** (TTS) + **Qdrant** (vector search). Voice must be essential, not decorative.
- **DragonForge**: Research/experiment with **Pathway's BDH (Dragon Hatchling)** architecture. No training required — build explainers, benchmarks, visualizations, or evaluation tools.

## Submission Requirements
- Public GitHub repository with README (setup/run instructions)
- PPT (official template, publicly accessible)
- ≤4 min video (Google Drive, "anyone with link can view")
- Working proof: live feature, reproducible experiment, test, benchmark, visualization, or measurable improvement
- Architecture diagram / experiment flow
- Limitations & team contributions documented

## Key Constraints
- Team size: 2–4 members
- No exposed API keys/credentials
- Use synthetic/de-identified data for sensitive domains
- AI-assisted coding allowed; team must explain implementation
- Prize: ₹80,000 (₹40k cash + $450 Rime tokens)
